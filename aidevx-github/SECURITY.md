# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately instead, using GitHub's **"Report a vulnerability"** button in the **Security** tab of the affected repository.

Please include:

- which project and version is affected
- steps to reproduce the problem
- the possible impact

We will reply within 7 days and keep you updated until the issue is fixed. With your permission, we will credit you in the release notes.

## Supported versions

Only the latest release of each project gets security fixes.
