### What we build

AiDevX is a home for open source projects at the meeting point of AI and software development. The logo says it: two brackets, `>` and `<`, meeting to make the X.

We follow three rules in every project:

- **Open by default.** Code is open source. Data is open data that anyone can reuse.
- **Measured, not marketed.** Stars, commits, releases and licenses come from real data, never from paid placement.
- **Built for developers.** Filters, docs and examples for the frameworks and editors developers actually use.
